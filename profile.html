Tentang Saya

Halo! Saya Michael Wung, siswa Kelas XI.3 di SMA Cinta Kasih Tzu Chi. Saya memiliki minat mendalam di bidang rekayasa perangkat lunak khususnya pengembangan web, desain grafis, dan UI/UX.

Bagi saya, belajar pemrograman adalah cara untuk melatih logika berpikir sistematis sekaligus wadah berkreasi untuk memecahkan masalah sehari-hari. Saya terbiasa mengeksplorasi pembuatan aplikasi web responsif menggunakan HTML, CSS, JavaScript, Tailwind CSS, serta dasar-dasar backend dengan Node.js. Portal web ini saya dedikasikan sebagai jurnal digital untuk menyimpan dokumentasi seluruh tugas sekolah serta proyek pengembangan aplikasi saya.
